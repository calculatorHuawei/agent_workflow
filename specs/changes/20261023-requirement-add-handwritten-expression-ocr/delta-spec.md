> 状态：PLANNING 定版。普通产品歧义已按 Issue 授权采用安全、可逆、最小范围默认值，详见 §5 与 §13。

## 1. 需求描述

| 设计资产 | 描述 |
|----------|------|
| IR标识 | IR-046 |
| 名称 | 拍照识别手写算式并自动填入 |
| 描述 | 通过相机采集纸面算式，OCR 后供用户编辑确认，经安全校验后填入计算器 |
| Who | OpenCalc 手机/平板用户 |
| Where | CalculatorPage 前台交互 |
| When | 用户希望录入纸面算式时 |
| Why | 降低复杂算式逐键输入成本 |
| What | 权限、拍照、识别、确认编辑、安全解析、填入、失败重试 |
| How | 识别编排器 + 平台 gateway + 端侧离线 OCR provider + 严格表达式验证器 |
| 类别 | 设计类 |

### 价值

以可恢复、可确认且不会隐式执行的方式增加图像输入通道，在提高录入效率的同时保护用户原输入和计算安全边界。

## 2. 术语与缩写

| 术语/缩写 | 定义 |
|-----------|------|
| OCR | 从图片识别文字的能力 |
| 候选文本 | OCR 原始结果经基础归一化后、尚未确认的文本 |
| 完全识别率 | 一张测试图片输出的规范化表达式与真值完全相同的比例；固定测试集目标 ≥90% |
| 永久拒绝 | 系统不再弹出权限申请，需要用户到设置页授权的状态 |
| 安全解析 | 在求值前执行的长度、字符、Token、括号和语法完整性校验 |

## 5. 假设和约束

| 序号 | 约束类别 | 约束描述 | 对验收的影响 |
|------|----------|----------|----------------|
| 1 | 安全 | OCR 文本为不可信输入，禁止动态执行或直接求值 | 必须证明无自动 evaluate 调用 |
| 2 | 数据保护 | 失败、拒绝、取消、空结果、不支持字符、重拍均不覆盖原输入 | 每条异常路径必须断言原值 |
| 3 | 用户控制 | 用户可编辑并显式确认；确认仅填入，不计算 | UI/状态测试必须覆盖 |
| 4 | OCR 路线 | 首期仅端侧离线；禁止静默降级到云端 | 断网验收；无网络/账号/密钥依赖 |
| 5 | 字符范围 | `0-9`、`.`、`+ - × ÷ * /`、圆括号；不支持隐式乘法/函数/常量/变量/多行 | 白名单、grammar 与数据集按此验收 |
| 6 | NFR | 100 张清晰单行固定集（≥5 名书写者）完全识别率 ≥90%；P95 ≤2 s；5 s 超时 | 形成准确率与性能门禁 |
| 7 | 填入语义 | 显式确认后以规范化候选替换当前表达式；不追加、不自动计算 | 确认前断言原值，确认后断言替换 |
| 8 | 临时数据 | 不持久化图片/候选，离开会话释放 | 需生命周期验证 |
| 9 | 长度限制 | 候选最多 128 个 Unicode code unit | 超限不可确认，可编辑或重拍 |

## 6. 分级规格

### 6.1 识别结果分级

| 级别 | 条件 | 可编辑 | 可确认填入 | 行为 |
|------|------|--------|------------|------|
| RG-0 | OCR 成功且安全校验通过 | 是 | 是 | 显示规范化候选 |
| RG-1 | OCR 成功但结果为空 | 否 | 否 | 提示未识别到算式，可重拍 |
| RG-2 | 含不支持字符或语法不完整 | 是 | 否 | 定位/说明错误，修改或重拍 |
| RG-3 | 权限/拍照/OCR 系统错误 | 否 | 否 | 保留原输入并提供恢复动作 |

### 6.2 状态机规则

- 允许状态：IDLE、REQUESTING_PERMISSION、CAPTURING、RECOGNIZING、REVIEWING_VALID、REVIEWING_INVALID、ERROR。
- 每次开始创建唯一 session id；不属于当前 session 的异步结果必须丢弃。
- `CONFIRM` 只允许从 REVIEWING_VALID 进入 IDLE 并提交。
- `CANCEL/CLOSE` 从任意非 IDLE 状态返回 IDLE，且不提交。
- `RETRY` 仅从 ERROR/REVIEWING_* 返回 CAPTURING，且不提交。

### [ADD] 用例 SC005-UC001：丢弃迟到结果
