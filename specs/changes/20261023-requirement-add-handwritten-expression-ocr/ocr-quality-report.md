- 目标：HarmonyOS emulator 6.1.0.126(SP1DEVC00E120R4P11)
- HDC：3.2.0d
- 应用：`com.darkempire78.opencalculator`

## 已验证

- HAP 安装、冷启动和 CalculatorPage 前台运行成功。
- UI 树显示“📷 识别”入口及无障碍文本。
- 首次权限弹窗展示资源化用途说明；拒绝后显示可理解的恢复 UI，应用未崩溃。
- 第二次请求识别为永久拒绝，并提示进入系统设置；原表达式 `7+8` 保持不变。
- 授权后模拟器无法提供真实相机采集，应用稳定进入“拍照或识别失败，请重拍”状态，无崩溃。
- 57 个 Local Test 全部通过，覆盖规范化、白名单、grammar、权限错误、确认门禁、空结果、超时、重试、取消和迟到回调。

## 未满足的设备门禁

- 缺少已审计的 100 张、至少 5 名书写者固定数据集，不能报告或声称完全匹配率 ≥90%。
- 模拟器不具备物理相机，不能证明真实拍摄完成、飞行模式端到端 OCR、P95 ≤2 秒或照片质量适配。

结论：自动化逻辑、API 编译和模拟器恢复路径通过；真实 OCR 准确率/性能/离线门禁阻塞，须由 Tester 在支持 CoreVisionKit OCR 的物理设备与固定数据集上完成。
