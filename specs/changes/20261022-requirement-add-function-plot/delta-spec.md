## 1. 需求描述

| **设计资产** | **描述** |
| ------------ | -------- |
| IR标识 | ISSUE-40-R1/R2/R3（见 proposal.md §7） |
| 名称 | 函数图像绘制：输入 sin(x) 显示曲线 |
| 描述 | 为 OpenCalc HarmonyOS 增加变量 x 表达式求值、固定范围采样与 Canvas 曲线渲染；含坐标轴、无效点断线与返回计算器流程 |
| Who | OpenCalc 科学计算器终端用户 |
| Where | OpenCalc HarmonyOS 应用（单 @Entry 页面，新增全屏绘图覆盖面板） |
| When | 用户在计算器主界面点"绘图"入口进入；输入含 x 的表达式后触发绘制 |
| Why | 基线只支持数值求值，缺"计算→可视化"能力；Issue #40 验收标准要求 |
| What | 变量 x 求值、[-2π,2π] 采样分段、坐标轴+曲线 Canvas 渲染、无效点断线、返回流程 |
| How | CalcEngine 可选变量绑定 + Expression 隐式乘法扩展 + 新增 FunctionPlotter 纯逻辑采样器 + PlotPanel Canvas 面板 |
| 类别 | 设计类 |

### 价值
补齐数值计算→函数可视化链路；以 `x^2` 抛物线证明引擎表达力非 sin 硬编码；为后续缩放/平移/自定义范围增强提供骨架。

## 2. 术语与缩写

| 术语/缩写 | 定义 |
| --------- | ---- |
| 采样点 | 自变量 x 在 [-2π,2π] 上的等距取值及对应函数值 y |
| 无效点 | y 为 NaN/±Inf，或该点求值置位 ErrorFlags 的采样点 |
| 分段（Segment） | 相邻有效采样点构成的连续折线段序列 |
| ErrorFlags | 既有全局错误标志对象（除零/定义域/语法/无穷大/需实数） |
| 清洗表达式 | 经 Expression.getCleanExpression 预处理后的表达式 |

## 5. 假设和约束

| 序号 | 约束类别 | 约束描述 | 对验收的影响 |
| ---- | -------- | -------- | ------------ |
| 1 | 行为约束 | 绘图固定弧度制（isDegree=false），与计算器弧度模式设置解耦 | 保证 AC"sin(x) 在 [-2π,2π] 连续正弦曲线"成立 |
| 2 | 范围约束 | 采样范围固定 [-2π,2π]、401 点；缩放/平移/自定义范围不做 | 增强项缺失不阻塞验收 |
| 3 | 兼容约束 | 无变量绑定的既有表达式求值行为、错误文案不变；xp/e^x 函数不受 x 扩展影响 | 防止既有功能退化（Issue AC） |
| 4 | 架构约束 | 不新增 @Entry 页面、不改 main_pages.json/module.json5；PlotPanel 为 CalculatorPage 内 Builder | 降低导航/生命周期回归风险 |
| 5 | 精度约束 | number（IEEE 754）精度；|y| 与理论值比较允许 1e-9 相对误差 | 单测断言阈值依据 |
| 6 | 假设 | y 轴范围取有效样本 min/max + 10% padding，min==max 时 ±1 | sin(x) 视图默认舒适，x^2 完整可见 |
| 7 | 范围约束（R4） | 补救轮不做缩放/平移/用户自定义范围（用户明确排除） | 防止补救范围蔓延 |
| 8 | 可读性约束（R4） | 坐标系文字标签字号 ≥14px；浅色/暗色/AMOLED 三主题下标签/网格均与面板背景可区分；网格线先于曲线绘制 | PR #41 审查意见"10px 不可接受"不复现 |
