# 函数图像绘制（sin(x)） 需求提案

> 关联 Issue：calculatorHuawei/agent_workflow#40（支持绘制函数图像：输入 sin(x) 显示曲线）
> 产出 skill：rq-parse + rq-clarify（自主会话：无人类可交互，模糊点按 Issue 验收标准裁决或记录工程默认值）

## 1. 需求概述

### 1.1 基本信息
- **功能名称**：函数图像绘制（function plot）
- **需求类型**：新增功能
- **关联全局文件**：specs/spec.md / specs/arch.md / specs/design.md

### 1.2 需求描述
为 OpenCalc HarmonyOS 科学计算器增加函数图像绘制能力：用户在应用 UI 中输入（或选择）含变量 `x` 的函数表达式（如 `sin(x)`），触发绘图操作后，在独立、清晰的图像区域看到函数曲线；图像显示横纵坐标轴，`sin(x)` 在 `[-2π, 2π]` 范围内呈连续正弦曲线；曲线不得跨越无效采样点或把非有限值错误连接；用户可从图像界面返回计算器，且基础计算、科学计算、历史、设置功能不退化。

### 1.3 使用场景
用户完成数值计算后想直观理解函数形态：输入 `sin(x)` 查看正弦曲线；输入 `x^2` 查看抛物线（验证实现非针对 sin 硬编码）；查看后返回计算器继续计算。

### 1.4 预期效果
- 计算器界面可进入绘图界面并输入含 `x` 的表达式
- 触发绘制后显示带坐标轴的曲线，`sin(x)` 在 `[-2π, 2π]` 连续光滑
- `tan(x)` 等含非有限值/定义域外点的表达式曲线在无效点处断开，不错误连线
- 返回计算器后原有功能（四则、科学函数、历史、设置）全部可用

### 1.5 背景与价值
#### 问题背景
基线 `agent-test/baseline-opencalc-source` 仅支持 `sin(数值)` 求值，不支持变量 `x`、函数采样或图像绘制；用户无法从数值计算进入函数可视化。

#### 需求价值
为计算器补齐"计算 → 可视化"链路，验证数值引擎的通用表达能力（变量 + 采样），并为后续缩放/平移/自定义范围等增强项打好骨架。

#### 核心问题
能力缺位：解析器无变量绑定、无采样机制、无图形渲染区域、无绘图入口。

#### 不做什么（边界）
- 不做缩放、平移、自定义范围与步长（增强项，不作为本次通过必要条件）
- 不做多函数叠加绘制、不做图像导出/分享
- 不改动计算/历史/设置的既有行为

### 4.1 已澄清的关键决策
| # | 问题 | 决策 | 来源 |
|---|------|------|------|
| 1 | 绘图角度模式 | 绘图固定使用弧度（`isDegree=false`），与计算器"弧度模式"设置解耦 | Issue 验收标准："sin(x) 在 [-2π,2π] 连续正弦曲线"只有弧度制成立 |
| 2 | 绘图界面形态 | 全屏 PlotPanel 覆盖层（CalculatorPage 内 @Builder + Stack 叠放），ToggleRow 增加"绘图"入口，面板内提供"返回" | 工程默认：与 History/Settings/About 面板同模式，回归风险最小 |

| 4 | 采样范围/密度 | 固定 `[-2π, 2π]`，401 个等距采样点 | 工程默认：满足 AC，密度足够平滑 |
| 5 | 非有限值处理 | 每个采样点独立求值；非有限值（NaN/±Inf）或 ErrorFlags 置位的点标记无效，曲线在该点断开（分段 moveTo），不连线 | 工程默认：直接满足 AC"不得跨越无效采样点" |

### 4.2 待定假设
- y 轴范围：由有效采样点的 min/max 自适应 + 10% padding；min==max 时取 ±1（使 sin(x) 默认视图舒适、x^2 抛物线完整可见）
- 绘图表达式不进入历史记录、不持久化（边界外功能）
- 采样点错误标志互不串扰：每点求值前 reset ErrorFlags

### 4.3 功能边界
- **包含**：`x` 变量解析与隐式乘法、绘图入口、全屏绘图面板（坐标轴 + 曲线 + 返回）、`[-2π,2π]` 固定范围采样、无效点断线、`sin(x)` 与 `x^2` 验证
- **不包含**：缩放/平移/自定义范围步长、多函数叠加、图像导出、绘图历史持久化、横屏专用绘图布局（面板自适应即可）

## 5. 特性清单

- **F1: 变量 x 表达式支持**
  - 功能描述：解析器支持变量 `x` 绑定求值；预处理支持 `x` 的隐式乘法（`2x`→`2*x`、`x(x+1)`→`x*(x+1)`、`πx`→`π*x`）；不破坏 `xp`（e^x）等既有函数名
  - 用户价值：可定义以 x 为自变量的函数表达式
  - 技术要点：`evaluate` 增加可选变量参数（默认无 → 行为不变）；addMultiply 中 `x` 与 `xp` 的区分
  - 子特性：
    - F1.1: 解析器变量绑定 — `fn==='x'` 且绑定生效时返回变量值
    - F1.2: 隐式乘法扩展 — `x` 与数字/括号/常量/函数相邻时插入 `*`

- **F2: 函数采样器**
  - 功能描述：对清洗后的表达式在 `[-2π,2π]` 等距采样 401 点，产出分段（连续有效段）数据；无效点（非有限值/错误标志）断段
  - 用户价值：把表达式转为可渲染的几何数据
  - 技术要点：纯逻辑类（不依赖 UI），每点独立 reset/检查 ErrorFlags；弧度制求值
  - 子特性：
    - F2.1: 采样求值 — 逐点求值并标记有效性
    - F2.2: 分段构建 — 相邻有效点连段，无效点断段

- **F3: 绘图界面与渲染**
  - 功能描述：ToggleRow 增加"绘图"入口；全屏 PlotPanel 含表达式输入（预填主界面表达式）、`x` 插入按钮、Canvas 图像区（横纵坐标轴、x 轴刻度 -2π/-π/0/π/2π、曲线）、"返回"按钮
  - 用户价值：独立清晰的图像区域与显式返回路径
  - 技术要点：Canvas 2D 折线分段绘制；坐标映射（数学坐标 → 画布像素）；主题色适配（3 主题）
  - 子特性：
    - F3.1: 绘图面板 UI — 输入区 + Canvas + 返回
    - F3.2: 坐标轴与刻度 — 横纵轴 + π 刻度标签
    - F3.3: 曲线渲染 — 分段折线，断开无效区间

## 7. 需求规格

- **R1: 变量 x 表达式求值**
  - 描述：表达式中的小写 `x` 在绑定值下参与求值；含 `x` 的表达式在未绑定时保持既有报错行为
  - 需求价值：函数表达式的语义基础
  - 使用场景：输入 `sin(x)`、`x^2`、`2x+1` 等
  - 验收标准：
    - AC1: 绑定 `x=1` 时 `sin(x)`≈0.8414709848（弧度）
    - AC2: 绑定 `x=2` 时 `x^2`=4、`2x+1`=5、`x(x+1)`=6
    - AC3: 无变量绑定时 `sin(x)` 求值报"表达式错误"（既有行为不回归）
    - AC4: `xp`（e^x）函数行为不受影响
  - 优先级：P0
  - 关联特性：F1

- **R2: 函数采样与分段**
  - 描述：在 `[-2π,2π]` 等距采样 401 点，弧度制逐点求值，非有限/错误点无效并断段
  - 需求价值：将表达式转为正确、可渲染的几何数据
  - 使用场景：每次触发"绘制"
  - 验收标准：
    - AC1: 采样点数 401，x 覆盖 [-2π,2π]（含端点，步长 π/100）
    - AC2: `sin(x)` 全部 401 点有效，|y|≤1+ε
    - AC3: `1/x` 在 x=0 处无效，且该点两侧分为两个连续段（不断言跨 0 连线）
    - AC4: `sqrt(x)` 仅 x≥0 段有效
    - AC5: `tan(x)` 在 ±π/2 附近无效点断段，不错误连线
  - 优先级：P0
  - 关联特性：F2

- **R3: 绘图界面与返回流程**
  - 描述：ToggleRow 提供"绘图"入口；全屏面板含表达式输入（预填）、`x` 插入、绘制触发、坐标轴（x 轴刻度 ±2π/±π/0）、分段曲线渲染、"返回"按钮；主题适配
  - 需求价值：独立清晰图像区 + 无退化返回路径
  - 使用场景：从计算器进出绘图界面
  - 验收标准：
    - AC1: 竖屏主界面可见"绘图"入口，点击进入全屏绘图面板
    - AC2: 输入 `sin(x)` 触发绘制后，可见横纵坐标轴与 `[-2π,2π]` 连续正弦曲线
    - AC3: 输入 `x^2` 可显示抛物线（证明非 sin 硬编码）
    - AC4: 点击"返回"回到计算器，表达式/历史/设置可用
    - AC5: 空表达式或无 `x` 变量绑定失败时给出错误提示，不崩溃
  - 优先级：P0
  - 关联特性：F3

### 12.3 R5 需求规格
- **R5: 渐近线视觉分离与坐标轴可辨（结果修复 + 持久化测试）**
  - 描述：分段构建时仅保留"可绘制"采样点：①y 超出内收视窗 [yMin+inset, yMax−inset] 的点断段；②每个断口（无效点/视窗裁剪）后的首个可绘制点阴影化（不参与连线）。效果：1/x 两支距 Y 轴 ≥2 采样步长、log(x) 不再贴轴冲出底边、tan(x) 各渐近线两侧留出间隔、任何绘制点都在画布内收视窗中；坐标轴以主文字色 2px 绘制于曲线之上，与曲线/网格清晰区分

  - 使用场景：绘制 1/x、log(x)、tan(x) 等含渐近线/定义域边界的函数
  - 验收标准：
    - AC1: 1/x 分段 ≥2，任一绘制点 \|y\| ≤ yMax−inset+ε；绘制点最小 \|x\| ≥ 2 采样步长（曲线与 Y 轴留出可见走廊）
    - AC2: log(x) 仅绘制 x>0，绘制点最小 x ≥ 2 采样步长，最低绘制点不贴 y 下边（≥ yMin+inset−ε）
    - AC3: tan(x) 各渐近线两侧留出间隔：每段所有点位于同一 π/2 区间，绘制点距最近渐近线 ≥2 采样步长

    - AC6: 坐标轴清晰可辨：轴以主文字色（getT1）2px 绘制且在曲线之后（覆盖曲线），三主题下与曲线色/网格色可区分（代码审查 + Tester UI）
