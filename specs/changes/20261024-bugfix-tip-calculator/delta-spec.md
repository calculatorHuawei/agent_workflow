# 需求SPEC：小费计算器与多人账单分摊

---

## 1. 需求描述

| **设计资产** | **描述** |
| ------------ | -------- |
| IR标识 | IR-001～IR-007 |
| 名称 | 小费计算器与多人账单分摊 |
| 描述 | 在 OpenCalc 内提供隔离的小费表单，基于账单、比例和人数即时显示小费、总额及每人金额，并对非法输入防误导处理 |
| Who | 需要在多人消费后计算和分摊账单的终端用户；后续独立 Tester |
| Where | OpenCalc HarmonyOS 单页应用内 |
| When | 用户结账分摊时；Tester 在实现完成后的验证阶段 |
| Why | 降低手工计算、舍入和分摊错误 |
| What | 入口、受约束输入、预设/自定义比例、即时计算、货币舍入、错误提示、回归隔离和测试证据 |
| How | 复用单页覆盖层惯例，使用本地纯逻辑计算；不增加网络、权限、路由或持久化 |
| 类别 | 设计类 |

### 价值
用户能在同一计算器应用中快速获得可核对的分摊结果；明确的错误状态避免除零、旧结果残留和错误比例造成误导。

## 2. 术语与缩写

| 术语/缩写 | 定义 |
| --------- | ---- |
| 账单金额 | 不含小费的非负金额输入，最多两位小数 |
| 小费比例 | `0% / 10% / 15% / 20%` 预设或 `0%–100%` 自定义比例 |
| 小费金额 | 账单金额 × 小费比例，四舍五入到分 |
| 总额 | 账单分值 + 已舍入小费分值 |
| 每人应付 | 总额 ÷ 有效人数，四舍五入到分 |
| IR | Issue 原始需求原子 |
| AC | 可执行、可观察的验收标准；同目录 JSON 为 ID 权威来源 |

## 6. 分级规格

### 6.1 输入状态分级
| 级别 | 条件 | 结果区 | 错误反馈 | 是否计算 |
|------|------|--------|----------|----------|
| L0 初始 | 账单未触碰且为空 | `--` | 不显示 | 否 |
| L1 有效 | 三字段均满足约束 | 三项两位小数 | 无 | 是 |
| L2 字段错误 | 任一字段为空/格式非法/越界 | 三项 `--` | 对应字段明确提示 | 否 |
| L3 数值过大 | 计算无法保持有限安全分值 | 三项 `--` | 数值过大提示 | 否 |

### 6.2 状态机规则
- 所有输入事件先清理派生结果，再执行完整校验；只有 L1 进入计算。
- 点击预设比例切换到预设态并清理自定义比例错误；编辑自定义输入切换到自定义态。
- L2/L3 修正为有效值后，无需额外点击即回到 L1。
- 退出 TipPanel 不改变主计算器状态；应用重启不承诺恢复 TipPanel 表单。

| **A** 参与者 | 终端用户 |
| **S** 系统状态 | L1→L2/L3→L1 |

#### 用例 SC003-UC001：金额错误与恢复
- **Actor**：终端用户。
- **前置条件**：已有有效结果。
- **最小保证**：非法期间结果为 `--`，不保留旧值。
- **成功保证**：空、非数字、负值、过大值被拒；修正自动恢复。
- **触发事件**：编辑账单金额。


## 9. 需求DFX分析

### 9.1 威胁建模需求
不涉及账户、网络、支付或敏感数据。输入只在本地页面状态中存在；不记录账单内容到日志或历史。

### 9.2 可靠性分析需求（FMEA 消减措施清单）
未调用可选 dfr-fmea-general；但基于场景做最小可靠性分析：

| 措施编号 | 故障模式 | 故障原因 | 故障影响 | 改进措施（可验证表述） | 影响功能名称 |
| -------- | -------- | -------- | -------- | ---------------------- | ------------ |
| CM-01 | 无效人数进入除法 | 校验与计算耦合 | Infinity/NaN 或崩溃 | 人数通过 ≥1 整数校验前禁止计算；AC-008 | 校验与恢复 |
| CM-02 | 无效输入仍显示旧结果 | 仅更新错误未清派生状态 | 用户误读 | 每次重算先清结果，非法态统一 `--`；AC-007～009 | 校验与恢复 |
| CM-03 | 二进制浮点舍入漂移 | 直接链式 number 运算 | 金额差 0.01 | 采用分值和明确舍入顺序；AC-006 | 即时货币计算 |
| CM-04 | 比例多选状态冲突 | 多个布尔状态独立 | 计算比例与视觉不一致 | 单一模式/比例状态；AC-005/009 | 输入与比例 |
| CM-05 | 小费计算污染历史 | 复用 onEquals | 既有历史变化 | 独立 TipCalculator，不调用 onEquals/setHistory；AC-010 | 兼容性 |
| CM-06 | 横屏无入口 | ToggleRow 仅竖屏渲染 | 功能不可达 | 横屏 DisplayPanel 操作区提供入口；AC-001 | 隔离入口 |

### 9.3 DFX 质量属性遵从性分析
| SDR编号 | SDR名称 | SDR分析结果（可验证表述） | 影响功能 |
| ------- | ------- | ------------------------- | -------- |
| SDR-01 | 可靠性 | 任一非法字段不得进入计算；结果不含 NaN/Infinity | SR-02/03 |
| SDR-02 | 可用性 | 输入变化即时刷新；错误字段就近提示；横竖屏可达 | SR-00/01/03 |
| SDR-03 | 兼容性 | 主状态与历史前后相等；无新依赖/权限/路由 | SR-04 |
| SDR-04 | 可测试性 | 纯逻辑模块可单测，UI 元素提供稳定标识，AC 有精确 oracle | SR-01～05 |
| SDR-05 | 隐私 | 账单输入不持久化、不写历史/日志、不联网 | 全部 |

其他可服务性、生命周期、节能减排、可制造可供应和功能安全：无专项要求；本地 O(1) 计算且无后台任务。
