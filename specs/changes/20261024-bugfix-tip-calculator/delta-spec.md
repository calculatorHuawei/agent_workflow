# 需求 SPEC：小费计算器与多人账单分摊

> 版本：2026-10-25 Tester 反馈迭代 1。机器权威 AC 为同目录 `acceptance-criteria.json`。

## 1. 需求描述

| 设计资产 | 描述 |
|---|---|
| IR 标识 | IR-001～IR-014 |
| 名称 | 小费计算器与多人账单分摊 |
| 描述 | 输入账单、比例和人数，即时显示小费、总额和每人应付；纠正真机可见输入与计算快照脱节 |
| Who | 需要分摊账单的终端用户；独立 Tester |
| Where | OpenCalc 的 CalculatorPage 单页覆盖面板 |
| When | 用户结账分摊；Tester 对 PR #53 反馈迭代复测 |
| Why | 避免手工换算、分摊错误和 UI 陈旧结果误导 |
| What | 入口、输入、比例、计算、校验、状态同步、兼容性和证据 |
| How | 页面响应式单一源状态 + 无副作用分值计算器 |
| 类别 | 设计类；产品新增功能，编排类型 bugfix |

### 价值
在不增加权限、网络、支付或持久化的前提下提供可验证的账单分摊，并保证真机 UI 所见即计算所用。

## 2. 术语与缩写

| 术语 | 定义 |
|---|---|
| 分值 | 以 0.01 货币单位为整数的金额表示 |
| basis point | 百分比的 0.01%，0%～100% 对应 0～10000 |
| 源状态 | 页面唯一拥有的账单、人数、比例模式和自定义比例 `@State` |
| 派生状态 | 从同一源状态快照得到的错误、tip、total、perPerson |
| 陈旧快照 | UI 可见输入已变化，但计算仍读取旧的第二份状态 |

## 6. 分级规格

### 6.1 输入状态分级
| 级别 | 条件 | 结果 |
|---|---|---|
| S0 初始 | 账单未触碰 | 无错误，三结果 `--` |
| S1 有效 | 三输入通过校验 | 精确两位结果 |
| S2 非法 | 任一输入非法 | 对应字段错误，三结果 `--` |

### 6.2 状态机规则
`S0/S1/S2` 仅由当前页面源状态快照决定；每个输入事件完成一次 `写源状态 → 求值 → 原子提交派生状态`，不得从第二个可变会话对象回写源状态。

### [MOD] 场景 SC-001：进入、计算与即时同步

#### 场景描述
用户从主计算器进入覆盖面板，用真实键盘和比例按钮输入数据，系统以同一可见快照即时显示三项结果。

#### 场景要素分析
| T | G | E | A | S |
|---|---|---|---|---|
| 页面运行期 | 正确分摊且所见即所得 | HarmonyOS 横/竖屏、系统 IME | 用户、ArkUI | S0/S1 |

#### 用例 SC001-UC001：入口与核心示例
- **Actor**：终端用户（主）、HarmonyOS IME（次）。
- **前置条件**：CalculatorPage 可用；无新增权限。
- **最小保证**：返回后主计算器状态不变。
- **成功保证**：核心示例显示精确结果。
- **触发事件**：点击小费入口并输入。
- **主路径**：进入 → 输入 `100`/`2` → 选择 `15%` → 查看结果 → 返回。

##### 验证达成标准
- AC-001：Given 横/竖屏主界面；When 进入再返回；Then 面板可达且原主界面恢复。
- AC-002：Given 面板已打开；When 用系统键盘输入 `100`、`2` 并选择 `15%`；Then 可见值和结果精确为 `15.00/115.00/57.50`。
- AC-003：Given 面板已打开；When 输入 `88.80/10%/3`；Then 显示 `8.88/97.68/32.56`。

## 9. 需求 DFX 分析

### 9.1 威胁建模需求
不涉及网络、账号、支付、文件或新增权限；维持现有应用安全边界。

### 9.2 可靠性分析需求（FMEA 消减措施清单）
| 措施 | 故障模式 | 原因 | 影响 | 可验证改进 | 功能 |
|---|---|---|---|---|---|
| CM-01 | 可见有效值但结果 `--` | UI、页面、TipSession 多源状态脱节 | P0 功能不可用 | 页面单一源快照；AC-011 真机验证 | SR-02 |
| CM-02 | 非法人数进入除法 | 校验后置 | NaN/Infinity | 人数校验先于除法；AC-007 | SR-04 |
| CM-03 | 非法输入保留旧结果 | 派生状态非原子 | 用户误读 | 错误时三结果一次清空；AC-006～008 | SR-04 |
| CM-04 | 浮点舍入漂移 | 二进制浮点金额链 | 差 0.01 | 整数分值；AC-005 | SR-03 |
| CM-05 | 污染历史 | 复用主计算入口 | 回归 | 独立计算且不写 History；AC-009 | SR-00 |

### 9.3 DFX 质量属性遵从性
| 属性 | 结论 |
|---|---|
| 安全隐私 | 不新增权限、网络或敏感数据 |
| 可靠可用 | 字段校验、原子派生状态、设备回归 |
| 可维测 | 稳定 UI ID、精确 oracle、证据绑定 SHA |
