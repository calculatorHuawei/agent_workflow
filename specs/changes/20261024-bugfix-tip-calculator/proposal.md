# 小费计算器与多人账单分摊提案

## 1. 需求概述

### 1.1 背景与价值
多人聚餐或消费结账时，用户需要从账单金额、小费比例和人数快速得到小费、含小费总额及每人应付金额，避免手工换算和分摊错误。

### 1.2 核心问题
OpenCalc 当前只有普通/科学计算、绘图、历史与设置能力，没有面向账单分摊的受约束输入、货币舍入和即时结果界面。

### 1.3 本期范围
- 提供“小费”入口和独立覆盖面板。
- 输入账单金额、人数；选择 `0% / 10% / 15% / 20%` 或 `0%–100%` 自定义比例。
- 输入变化后立即计算并显示小费、总额、每人应付。
- 显示两位小数，对非法输入给出明确字段级提示并隐藏旧结果。
- 退出后普通、科学、绘图及历史状态保持不变。

### 1.4 非目标
- 不处理支付、收款、扫码或账单识别。
- 不支持按个人消费项目不等额分摊。
- 不把小费计算写入现有表达式历史，不持久化小费表单。
- 不补建当前代码仓中尚不存在的程序员模式。

## 2. 竞品/参考方案分析

未执行外部竞品调研。原因：Issue 已给出比例、公式、精度、异常和回归边界；采用常见的“预设比例按钮 + 自定义输入 + 即时派生结果”模式即可，不需要网络或新依赖。

### 3.1 意图分类
- **产品语义类型**：新增功能。
- **编排类型**：`bugfix`（来自任务载荷 `_orchestrator.change_type`，仅用于变更目录和路由，不改变需求语义）。
- **一句话概括**：在不干扰现有计算器状态和历史的前提下，新增可校验、即时更新、按货币精度舍入的小费分摊面板。

### 3.2 领域映射
- UI/交互：入口、输入框、比例按钮、自定义比例、结果卡和错误提示。

### 3.7 模糊点
| # | 类别 | 描述 | 严重程度 | 自主处理 |
|---|------|------|---------|---------|
| 1 | 交互 | 小费入口在现有单页中的呈现方式 | important | 沿用 PlotPanel 的覆盖层惯例，最小化路由和生命周期影响 |

| 5 | 超大值 | 可安全计算的上限未指定 | nice-to-have | 以 `Number.isFinite` 和安全分值范围为准，超出时提示“数值过大” |

## 4. 需求澄清（rq-clarify）

### 4.1 已澄清的关键决策
| # | 问题 | 决策 | 来源 |
|---|------|------|------|
| 1 | 面板形态 | 复用当前单页 Stack 覆盖层，关闭按钮返回 | 代码惯例 + 自治授权 |
| 2 | 初始值 | 15% 与 1 人；账单为空时仅显示占位，不立即报错 | 常见、安全、可逆默认值 |
| 3 | 计算顺序 | 小费先舍入到分；总额=账单+已舍入小费；每人=总额/人数后舍入到分 | 货币一致性默认值 |
| 4 | 表单生命周期 | 仅页面会话内；退出不写历史、不写 Preferences | 最小权限和兼容性原则 |
| 5 | 非法状态 | 任一字段非法时三项结果显示 `--`，仅显示对应字段错误；修正即自动恢复 | 防误导原则 |
| 6 | 程序员模式 | 当前仓库没有该模式，本变更不新增；设计保证不修改其未来/外部入口契约 | 范围最小化 |

### 4.2 待定假设
- 金额和自定义比例采用 `.` 作为小数点，最多 2 位小数；不接受指数、分组符或正负号。
- 账单金额允许 `0`；负值拒绝。
- 预设比例按钮选择后隐藏/清空自定义比例错误；编辑自定义比例后切换为“自定义”选中态。
- 关闭再打开面板保留本次页面生命周期内输入，应用重启不恢复。
- 结果数值不带货币符号，因为 Issue 未指定币种；只显示两位小数。

### 4.3 功能边界
- **包含**：入口、会话内表单、预设/自定义比例、即时计算、两位小数、字段校验、兼容性回归、测试可追溯设计。
- **不包含**：支付/扫码/个人明细、不等额分摊、币种与税费、跨启动持久化、远端服务、权限、程序员模式补建。

## 5. 特性清单

- **F1：小费入口与隔离面板** — 在横竖屏均可进入/退出，保留主计算器状态。
- **F2：账单输入与比例选择** — 金额、人数、四个预设比例及自定义比例的可见、互斥状态。
- **F3：即时货币计算** — 输入变化即派生小费、总额、每人金额并统一两位小数。
- **F4：防误导校验与恢复** — 非法字段明确提示、禁止除法、清除旧结果，修正后恢复。
- **F5：独立测试证据** — 后续 Tester 覆盖核心公式、边界、交互和回归并保存证据。

## 6. 系统架构概述

```text
CalculatorPage（既有 V1 @State 单页）
  ├─ 普通/科学/绘图/历史/设置（保持）
  └─ TipPanel（新增覆盖层）
       └─ TipCalculator（新增纯逻辑：parse → validate → calculate → format）
```

| 模块 | 职责 | 备注 |
|------|------|------|
| CalculatorPage | 入口、会话状态、条件渲染、主题/横竖屏适配 | 扩展既有 |
| TipPanel | 输入、比例选中态、错误与结果展示 | Builder，新增 |
| TipCalculator | 无副作用的确定性校验和分值计算 | 新增、可单测 |
| PreferencesStore/History | 保持原行为 | 不修改 |

数据流：用户输入 → `@State` 原始字符串/选择 → TipCalculator 返回验证或结果 → 面板重绘。无网络、文件、权限或持久化调用。

## 7. 需求规格

- **R1（P0）入口与兼容性**：横竖屏可进入小费面板并返回，主计算器表达式、结果、历史和模式状态不变。
- **R2（P0）输入与比例**：支持金额、人数、预设和 0–100 自定义比例；预设与自定义选中态一致。
- **R3（P0）即时计算**：任一输入变化后无需按钮即可更新小费、总额和每人金额。
- **R4（P0）货币精度**：三项金额固定两位；小费、总额、每人按明确顺序四舍五入到分。
- **R5（P0）校验**：空值、非数字、负金额、非法人数和越界比例显示字段级提示，结果不显示旧值。
- **R6（P1）验证证据**：Tester 独立生成并执行用例，证据按 AC ID 可追溯。
